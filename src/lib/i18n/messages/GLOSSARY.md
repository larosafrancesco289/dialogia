# Glossary

The words Dialogia uses for its own things, per language, so every screen calls a thing by one
name. The catalogues here (and the tutor's, in `src/modules/tutor/i18n/`) follow it; a new string
should too.

**Voice.** Plain words for people who are not technical, warm and direct, never corporate. The
informal address throughout: _tu_ (it, fr), _du_ (de), _tú_ (es), _você_ (pt-BR), _εσύ_ (el).
Buttons are verbs in each language's usual UI form: the imperative in Italian (_Salva_), the
infinitive in French, German, Spanish and Portuguese (_Enregistrer_, _Speichern_, _Guardar_,
_Salvar_), and a noun in Greek (_Αποθήκευση_). Where a sentence would otherwise pick a gender for
the reader, it is turned so it does not (_Te revoilà_, _Eccoci di nuovo_, _Boas-vindas_).

**Never translated.** Model output, the person's own words and titles, model names, provider and
product names (OpenRouter, Anthropic, Claude, Ollama, LM Studio, Tavily, Jina), the slash commands
(`/model`, `/search on`, `/reasoning high`) and their arguments, and the provider's own page names
in the connect steps (Credits, Keys, API keys, Billing).

**Typography.** Typographic apostrophes (’). Quotation marks as each language writes them: “…” (en,
it, pt-BR), „…“ (de), « … » with narrow no-break spaces (fr, added by the generator before ? ! ; and
a no-break space before :), «…» (es, el). Greek asks with ; and keeps its accents in lower case.
